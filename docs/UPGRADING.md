# 升级与登录资料

## 从旧版升级

3.0.1 起，Windows 发行版使用固定的资料目录：`%APPDATA%\LightWindow\data`。完成首次迁移后，以后更新可以解压到其他位置，仍会使用同一份登录资料。

如果你还在使用把 `data` 放在程序旁的旧版：

1. 退出所有旧版轻窗。
2. 在原程序目录覆盖更新一次，保留旁边的 `data` 文件夹。
3. 打开新版。程序会把旧资料复制到固定目录，原资料仍会保留。

程序也会检查相邻、按 `LightWindow-版本号-win32-x64` 命名的旧版目录。如果找到多份旧资料，会停止并提示你从原来使用的目录更新，避免选错。复制不完整时不会启用新资料。

已有固定资料目录时，程序优先使用它，不会再用其他解压目录中的旧资料覆盖。

## 资料保存位置

| 位置 | 内容 |
| --- | --- |
| `%APPDATA%\LightWindow\data\settings.json` | 透明度、窗口位置、尺寸等设置 |
| `%APPDATA%\LightWindow\data\sites.json` | 保存的网址、名称和当前网站 |
| `%APPDATA%\LightWindow\data\browser\` | 网站 Cookie、本地存储和登录资料 |

手动备份前请先退出软件。不要把这些资料上传到 GitHub，也不要附在问题反馈中。

## 哪些情况仍需要登录

网站主动注销、登录到期或网站要求重新验证时，仍需要按网站提示登录。程序保留本机资料，不能延长网站规定的登录期限。

删除网站入口不会清除它的登录资料。重新添加相同网站时仍会复用；这里的“相同网站”按网址的协议、域名和端口区分。同一个域名下不同路径通常共用登录状态。

默认粉笔入口继续使用旧版的 `persist:fenbi` 分区。正常退出会等待所有已打开网站保存 Cookie 和本地存储，包括留在后台的网站。

开发模式使用项目目录中被 Git 忽略的 `data`；测试使用独立目录，不读取真实登录资料。
