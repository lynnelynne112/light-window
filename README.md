# 轻窗 · LightWindow

这是一个桌面窗口，可以调节大小、透明度以及缩放。希望在你的场景中可以用得到。

[下载 Windows 版](https://github.com/lynnelynne112/light-window/releases/latest) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/lynnelynne112/light-window/issues)

目前提供 Windows 10/11 x64 版本，暂时没有 Mac 版。

## 怎么用

1. 下载 ZIP，解压整个文件夹，双击 **启动轻窗.vbs**。
2. 默认打开粉笔题库。点顶部的网站名称，可以添加、编辑和切换其他网站。
3. 先切到“始终显示”并调高可见度，完成网站登录。
4. 按需要调整窗口大小、可见度和网页缩放。开启“移入显示”后，鼠标移开会隐藏，移回窗口原来的位置会显示。

## 可以调整什么

- **窗口大小**：拖动四边或四角调整，缩小后按钮会收拢到菜单里。
- **透明度**：调节“可见度”，数值越低越透明，网页和工具栏会一起变淡。
- **网页缩放**：在“⋯”里调整文字和页面的大小，也可以点“适应”。
- **边框和工具栏**：点“无框”隐藏，右上角会留下一个小小的“⋯”，用来打开设置。
- **显示方式**：选择始终显示或鼠标移入时显示，也可以设置窗口置顶。

可以保存多个网址。切换网站时，已打开的页面会留在后台；同时打开越多，内存占用也会增加。退出后再次打开会重新加载网页，不会恢复未提交的表单。

## 常见问题

**窗口隐藏后怎么找回来？**

按 `Ctrl+Alt+Q`，或在系统托盘中找到轻窗图标，选择“显示窗口”。开启“移入显示”时，也可以把鼠标移回窗口原来的位置。轻窗默认不显示在任务栏中。

**窗口太小，找不到网站或设置按钮？**

点“⋯”打开菜单。添加网址需要更多空间时，窗口会暂时展开，关闭后恢复原来的大小。

**更新后需要重新登录吗？**

3.0.1 起，登录资料固定保存在本机，换一个解压目录也会继续使用。网站自身让登录过期时，仍需要重新登录。从旧版升级请先看[升级说明](https://github.com/lynnelynne112/light-window/blob/main/docs/UPGRADING.md)。

**登录资料保存在哪里？**

保存在本机的 `%APPDATA%\LightWindow\data`，包括网站登录、收藏的网址和窗口设置。分享软件时不要附带这个文件夹；反馈问题也不需要上传它。

**所有网站都能用吗？**

可以添加 HTTP/HTTPS 网址，但部分网站的特殊登录、视频播放或浏览器扩展可能不兼容。默认的粉笔入口可以修改或删除，轻窗与粉笔官方无关联。
