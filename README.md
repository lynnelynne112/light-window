# 轻窗 · LightWindow

一个可以调节整体透明度、鼠标移入显示的 Windows 小型网页窗口。支持保存多个网站、自由缩放和隐藏工具栏。

## 使用

1. 从 [Releases](https://github.com/lynnelynne112/light-window/releases/latest) 下载 Windows x64 便携版 ZIP，解压整个文件夹。
2. 双击 **启动轻窗.vbs**，也可以双击 `electron.exe`。
3. 点顶部的网站名称，添加你自己的网址。默认保留粉笔题库作为一个可编辑入口。
4. 先使用“始终显示”和较高可见度完成网站登录，再按需要调低可见度、开启移入显示。

这是本地桌面软件，GitHub 提供源码和下载，不能作为 GitHub Pages 网页运行。

## 功能

- **多网站**：添加、编辑、删除和切换入口；可以收藏当前页，最多保存 30 个网址。
- **保留页面**：已打开网站在本次运行中留在后台，切换回来保留滚动和网页中的选择。
- **独立登录资料**：按网址的 origin 隔离存储，同一 origin 的不同入口共用登录状态。
- **整体可见度 1–100%**：网页、图片和工具栏一起变淡。
- **移入显示**：移出平滑淡出，移入恢复；途中移回可自然反转。
- **无框和任意小窗口**：四边、四角可缩放，没有应用设置的最小宽高；小窗口按钮逐级收拢。
- **小型外观入口**：无框模式右上角为 20×20 的“⋯”，其余区域不被透明大面板占用。
- **不显示任务栏按钮**：保留托盘菜单，`Ctrl+Alt+Q` 持续隐藏 / 恢复。

普通窗口点顶部网站名称管理网站。窄窗口可在“⋯”中找到“网站”；极小窗口的“网站”菜单可直接切换。添加或编辑网址需要空间时，会临时展开窗口，关闭后恢复原尺寸。

切换网站不等于关闭网站：同时保留的网页越多，内存占用也会增加。重启软件后重新加载保存的入口，不保证恢复未提交表单或临时弹出页。

## 本地资料与旧版升级

| 位置 | 内容 |
| --- | --- |
| `data/settings.json` | 透明度、窗口位置、尺寸和显示偏好 |
| `data/sites.json` | 自己保存的网址、名称与当前网站 |
| `data/browser/` | 网站 Cookie、本地存储和登录资料 |

**不要把 `data` 文件夹提交到 GitHub 或打包分享。** 项目的 `.gitignore` 和打包脚本会排除这些资料。

从轻窗粉笔 2.x 升级时，在原运行目录替换应用资源并保留 `data`。默认粉笔网站继续使用原来的 `persist:fenbi` 浏览器分区。删除网站入口不会删除其磁盘登录资料；相同 origin 重新添加时仍复用对应分区。

本机升级不会复制任何浏览器资料到源码目录。不要使用新空文件夹覆盖原有 `data`。

## 开发

需要 Windows 10/11 x64、Node.js 22.12 或更新版本。

```sh
npm ci
npm test
npm start
```

桌面集成测试只使用本地模拟网站。测试窗口不可见，不代替用户登录或提交真实答案：

```sh
npm run test:desktop
npm run test:desktop -- --verify-restart
```

第二条应在第一条通过后执行，用于验证真正退出并重新启动后的 Cookie、存储和网站列表。设置 `LF_QA_PYTHON` 为 Python 路径时，还会运行只读 Win32 边缘命中检查；该检查使用原生透明度为零的无焦点窗口，不操作鼠标。

## 构建 Windows 便携包

```sh
npm ci
npm test
npm run check:source
npm run package:win
```

输出在 `dist/LightWindow-<版本>-win32-x64.zip`。打包采用源文件白名单和原始 Electron 运行时，不复制 `data`、QA 资料、个人网址、浏览器缓存或访问令牌。同版本目录已存在时脚本会停止，请移动旧构建或更新版本号后再构建。

GitHub Actions 会测试并构建下载附件；推送 `v*` 标签时，Release 工作流会发布 ZIP。**本地测试通过不代表 GitHub CI 已运行**，上传后仍应查看 Actions 结果。

## 兼容范围

- 当前验证平台为 Windows x64，其他系统未验证。
- 加载用户选择的 HTTP/HTTPS 网站，默认禁止摄像头、麦克风、定位等额外权限。
- 网页运行在沙箱中，不提供 Node.js 或本地文件接口。不要把本软件视为完整浏览器的安全替代品。
- 某些网站的 DRM、浏览器扩展、设备认证或专有登录流程可能不兼容。
- 应用当前未进行发布者代码签名，Electron 运行时二进制保持官方原始字节。

测试用网页截图用于核对界面，不代表已采集或验证用户桌面的透明叠加效果。
